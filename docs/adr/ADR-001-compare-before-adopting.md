# ADR-001: nugget 方式は、導入前にチャンク全体と同じ条件で比較する

**ステータス:** Draft  
**決定日:** 未確認（遡及記録: 2026-10-28）  
**review_by:** 2026-11-17

> 雛形: [ADR-000-public-template](https://github.com/flipslidersand-labs/repo-compass/blob/master/docs/adr/ADR-000-public-template.md)。遡及して書いた記録で、当時の比較経緯は推定していない。

## 課題

CoinRAG（arxiv 2608.07458）の「チャンク全体でなく、質問に関連するスパン（nugget）だけを LLM に渡す」方式を、
academic-paper-system に入れるかどうかを決める必要があった。

## 決定

導入する前に、チャンク全体（full-chunk）と nugget を、同じ質問セット・同じ取得候補・同じ指標（Recall@k、MRR@k、平均トークン量）で
比較する評価ハーネスを作る。評価結果が出てから導入を判断する。

## 理由

- 「関連する文だけを渡せば、トークンが減り、Recall も上がる」は仮説で、効果は測るまで分からない。
- **却下した代替案:** 評価せずに導入する。README の目的に「導入する前に定量評価する」と明記している。それ以外の代替案を比較した記録はない。
- 指標は、ヒットの有無（Recall@k）、順位（MRR@k）、渡す量（平均トークン）の 3 つ。トークン量は `words` か `chars` で見積もる。

## 影響

- 質問セット・取得候補・埋め込み条件を、2 方式で揃える必要がある。
- 結果は、使った質問セットの範囲でしか言えない（→ [ADR-003](ADR-003-gold-set-and-regression-gate.md)）。

## 再検討条件

評価セット・nugget の抽出方法・埋め込みモデルのいずれかを変えたとき。
